I used ChatGPT Plus throughout the project to help me create the user stories, write the Architecture Decision Record (ADR), and apply the new features to the existing code. The main features I worked on were the search and filter bar and the comments section. ChatGPT helped me understand how these features could be structured and how they would fit into the current backend and frontend.

I also used Claude to generate tests for the new code and check whether there were any faults or unexpected behaviors. This gave me more confidence that the features worked correctly. However, I still reviewed the tests and results myself instead of assuming that everything produced by AI was completely accurate.

AI initially slowed me down during the user stories and ADR stage. My first prompt was too weak and did not contain enough information about the project. As a result, the output was vague, unsuitable, and did not fully match the required features. I improved the prompt by clearly explaining the features I needed, the acceptance criteria, the project structure, and the programming languages and frameworks being used. After making the prompt more specific, the results became much more useful and relevant.

My own review also changed the final result, especially when developing the comments section. The first implementation caused errors when users tried to add or edit a comment. In addition, the original frontend design was inconvenient and made the feature harder to use than necessary. I identified these problems through manual testing and reviewing the generated code. I then adjusted the implementation and improved the interface so that comments were easier to add, view, and manage. This experience showed me that AI can support development, but it still requires clear instructions, careful testing, and human judgment. Overall, AI was useful, but the quality of its contribution depended heavily on my prompts and review.
